# Digital Clock Project

## Project Overview
A clean, functional digital clock that displays:
- Current hours (12-hour format)
- Current minutes
- Current seconds
- AM/PM indicator

## Features
- Real-time updates every second
- Clean, responsive design
- 12-hour format with AM/PM indicator
- Leading zeros for single-digit values

## How to Use
1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. The clock will automatically start and update every second

## Technologies Used
- **HTML5** - For the page structure
- **CSS3** - For styling and layout
- **JavaScript** - For real-time clock functionality
